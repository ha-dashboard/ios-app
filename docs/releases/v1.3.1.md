# HA Dashboard 1.3.1 Release Notes

Status: **Draft. Release candidate build 345 (`release/1.3.1` at `e0309e9`)
on soak since 2026-10-15 00:10 on iPad 2, iPad 4, iPad Mini 4, iPad Mini 5
and iPhone 16 Pro Max; go/no-go pending the soak review.**

Version 1.3.1 is built from `release/1.3.1`. Despite the patch number it is a
substantial release:

- French translation, contributed by @psolyca (PR #27), plus a bundling fix so
  it ships in builds made from the committed Xcode project.
- New native card: Home Assistant's built-in `clock` card (#21).
- Card fidelity fixes reported by @psolyca and @eoleedi: weather-forecast
  options (#20), timestamp tiles and blank names (#22), second headings and
  view badges (#23), media-control power and feature gating (#24), sections
  layout with `column_span` and per-card min/max widths (#25), entity-less
  buttons and HA's vertical button layout (#26).
- Reliability: exponential WebSocket reconnect backoff, and ~60× fewer
  entity-cache disk writes (a `diskwrites_resource` report on the Mini 5 for
  build 284 showed 4.3 GB in 6.2 h from the 5 s rewrite).

## App Store — What's New

New in 1.3.1

• HA Dash is now available in French. It follows your device's language, or
pick one in Settings.
• New: Home Assistant's clock card, in digital and analog styles.
• Button cards look like Home Assistant's, and buttons without an entity now
appear and run their action.
• Media control cards have a power button and only show the controls your
player supports.
• Sections dashboards match Home Assistant more closely, including sections
that span several columns.
• Every heading and badge in your dashboard is now shown, and badges support
hold and double-tap actions.
• Timestamp sensors show as times, weather forecast card options are
honoured, and many more layout fixes.
• Steadier reconnection when Home Assistant restarts.

Thanks to everyone who reported issues and to @psolyca for the French
translation.

## App Review Notes

Version 1.3.1 adds no new permissions, data collection or network
destinations. It adds a French localisation of the app interface and renders
more Home Assistant dashboard card types and options natively (a clock card,
button cards without an entity, media player power controls, and layout
options). Button cards can call Home Assistant services the user configured in
their own dashboard, exactly as other cards already could. Local Camera Stream
and Home Assistant remote controls are unchanged from 1.2.6; the 1.2.6 review
notes for those features still apply.

The app can be reviewed in Demo Mode without credentials. This version is
intentionally configured for manual release. Approval should leave it pending
developer release rather than publish it automatically.

## TestFlight — What to Test

1. **French:** set the device language to French (or pick Français in
   Settings) and check Settings, the kiosk banner and card labels read
   naturally. Entity states still follow your Home Assistant user's language.
2. **Clock card:** add a `clock` card (digital and analog) and check the time,
   seconds and date, including in a narrow column.
3. **Buttons:** a `button` card with only an icon, name and `tap_action`
   (e.g. `perform-action`) appears and runs its action; buttons show a large
   centred icon.
4. **Media control:** a TV that is off shows only a power button; turning it
   on shows its supported controls; ⋮ opens the details.
5. **Sections layout:** a sections view with `column_span: 2` sections and
   tiles with small `grid_options.columns` matches the Home Assistant web UI.
6. **Headings and badges:** a section with two heading cards shows both;
   view-level badges appear above the sections; heading badges show and
   respond to taps.
7. **Reconnection:** restart Home Assistant; the app should reconnect within
   about a minute without hammering the server.

## Technical changelog

Merges into `release/1.3.1` since v1.3.0 (first-parent order):

- **Weather forecast options (#20)** (0fdee90): `show_current`,
  `show_forecast`, `forecast_type`, `forecast_slots`, `round_temperature`,
  `secondary_info_attribute`; weather snapshot fixtures pinned to a fixed date
  (ac46bb2). Forecast-only cards no longer clip their last row (943d480).
- **WebSocket reconnect backoff** (87f7ec7): 2, 4, 8, 16 s then jittered
  30–60 s; reset on success, app-active and reachability.
- **Entity cache disk writes** (a813e16): writes at most every 300 s, skipped
  when unchanged (sha256), flushed on background/terminate/memory warning, one
  serial queue.
- **Native clock card (#21)** (220651a, e9b2815): `HAClockCardCell` and
  `HAClockCardFormatter`; digital/analog, date parts, 12/24 h, IANA time
  zones; shrinks to fit narrow columns.
- **Timestamp tiles and blank names (#22)** (42c2327): timestamp/uptime states
  are detected before numeric parsing; `time_format` (string or
  `{type, style}`); `name: " "` hides the name.
- **Headings and view badges (#23)** (d03dd78): later heading cards render as
  full-width heading rows; view-level `badges` (legacy and `type: entity`)
  render as a wrapping badge row in sections and masonry views.
- **Heading badges and alignment** (8f374d7): heading-card `badges`, badge
  hold/double-tap actions, section-header icon alignment, deterministic blur
  rendering in snapshot tests.
- **Light tile height** (cc6d9fb): tile cards are sized as tiles before domain
  height fallbacks; height logic moved to a testable class method.
- **Media control (#24)** (ef6b356, c5ddfb5): HA `computeMediaControls`
  gating for the card and the details sheet, power button, ⋮ more-info, MDI
  glyphs (U+23FB did not render on iOS 9), translated idle state;
  state-dependent card heights now invalidate the layout when they change.
- **Sections grid (#25)** (a42a121): per-card `getGridOptions` min/max clamp,
  legacy `layout_options` ×3 migration, section `column_span` with a
  12 × span sub-grid, HA default widths.
- **Entity-less buttons and button layout (#26)** (ca98a58, 9b656f2).
- **French translation (#27)** (f04eabe, 92ba7e0, cd4f60f): `fr.lproj` by
  @psolyca; 15 media-control accessibility strings translated for 1.3.1; `fr`
  added to the committed pbxproj and Info.plist.
- **Kiosk toast localised** (186967d).

## Known boundaries

- The App Store build still requires iOS 15; iOS 9–14 users install the
  universal IPA.
- The app keeps its own iPad column count in sections views (denser than HA at
  1024 pt); `row_span` and dense section placement are not supported.
- Not supported yet: button-type heading badges, `tap_action` on headings
  inside grids, badge `show_entity_picture`, browse media and speaker
  grouping, `time_zone: server` on the clock card, and `custom:layout-card`.
- App Store metadata is English only.
