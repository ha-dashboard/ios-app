# HA Dashboard 1.3.0

These are the public notes for the v1.3.0 tag workflow.

## Home Assistant's own names for states

Entity states, attribute names and attribute values now use Home Assistant's
own translations, in your Home Assistant user's language, so the app matches
the Home Assistant web interface:

- `not_home` now shows as "Away" (or "Absent" with a French Home Assistant)
  instead of the raw state. Thanks to @psolyca for reporting this in
  [#19](https://github.com/ha-dashboard/ios-app/issues/19).
- States are capitalised the way Home Assistant shows them.
- Climate, humidifier and water heater modes, and `hvac_action`, use Home
  Assistant's names.
- Free-text sensor states, such as a Wi-Fi network name, are shown exactly as
  reported, never reformatted.
- Translations are cached on the device, so they are used on a cold or
  offline start.

## Unsupported cards

Lovelace cards the app cannot display, such as unmapped `custom:*` cards, now
show a placeholder naming the card type instead of silently disappearing.
Turn this off in Settings → Display → Show Unsupported Cards for a clean kiosk
display. Conditional-card conditions are now applied once, and malformed card
configs, such as a card with a numeric `type`, no longer crash the app.

## Translations

The app is now translatable. All app text lives in
`HADashboard/en.lproj/Localizable.strings`. A language picker appears in
Settings once a second language ships. 1.3.0 itself is English only.

To contribute a language, see
[docs/translations.md](https://github.com/ha-dashboard/ios-app/blob/main/docs/translations.md).
Run `scripts/check-translations.sh --strict` before opening a pull request;
the `Translations / check-translations` workflow blocks partially translated
languages.

## Fixes

- Light cards are sized to the rows they show, so the name, sliders and
  percentage no longer overlap.
- The timer card's button row fits, with one shared font size.
- `<ha-alert>` in markdown cards starts on its own line.
- Fixed a thread-safety race in shared number formatting.

## Developer changes

- The snapshot test runner works on Xcode 27 and uses pinned iOS 18
  reference images.
- `-only-testing` filters narrow `scripts/test-snapshots.sh` runs.
- Test-harness sizing fixes, and `project.yml` excludes the reference image
  folders from the test sources.

## Which build to install

- **iOS 15 and later:** update from the
  [App Store](https://apps.apple.com/gb/app/ha-dash/id6759347912).
- **iOS 9.3.3 – 14.x:** the App Store only offers 1.2.5 on these versions, so
  **1.3.0 is only available from the universal IPA attached to this
  release.** Install it on a jailbroken device with AppSync Unified or a
  similar tool, or sideload it with a tool such as Sideloadly. With a free
  Apple ID, sideloaded apps must be re-signed every 7 days.

The universal IPA supports armv7 and arm64, with a minimum of iOS 9.0 in both
slices. Local Camera Stream still requires iOS 10.3.3 or later; Local Camera
Stream and remote-control behavior are unchanged from 1.2.6.

When reporting a bug, include your device, iOS version, and app version
(Settings → version).
